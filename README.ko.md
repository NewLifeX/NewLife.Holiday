> 이 번역은 중국어 버전보다 늦을 수 있습니다.

NewLife.Holiday는 중국 본토와 광시의 연도별 공휴일·대체휴일 데이터를 내장하고, 음력 명절·24절기·영업일 판정을 오프라인으로 제공합니다.

## 설치

```bash
dotnet add package NewLife.Holiday
```

## 빠른 시작

```csharp
using NewLife.Holiday;

var isHoliday = DateTime.Today.IsChinaHoliday();
```

## 주요 기능

- 기능과 데이터 내장, 외부 서비스 없이 동작
- net45~net10.0 다중 대상으로 기존 시스템에 원활히 적용
- MIT 라이선스, 상업적·사적 사용 자유

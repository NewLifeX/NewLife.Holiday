NewLife.Holiday incluye datos anuales de festivos de China continental y Guangxi, con festivos lunares, términos solares y cálculo de días laborables, sin conexión.

## Instalación

```bash
dotnet add package NewLife.Holiday
```

## Inicio rápido

```csharp
var holiday = new ChinaHoliday();
var isHoliday = holiday.Check(DateTime.Today);
```

## Características

- Capacidades y datos integrados; funciona sin servicios externos
- Destinos net45 a net10.0 para adoptarlo en sistemas heredados
- Licencia MIT; uso comercial y privado libre
